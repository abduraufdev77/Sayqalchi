Sayqalchi 0.5.0 preview for Apple silicon Macs · macOS 13+

1. Drag Sayqalchi into Applications and open it.
2. Click Enable Accessibility. In System Settings > Privacy & Security >
   Accessibility, add /Applications/Sayqalchi.app with the + button and turn it on.
3. If the shortcut is unavailable, quit and reopen Sayqalchi.
4. Double-press Right Shift, or double-click ö in the menu bar, to enable or
   pause Sayqalchi. New installations start paused; updates preserve your preference.
5. The compact notch indicator animates while you type. Pause for 650 ms to
   review a conversion of the entire editable field, including all paragraphs.
6. Review the converted text and click the combined ⌥ ↵ button, or press
   Option-Return. Escape
   dismisses it. Clicking Use keeps the original editor focused.

The Ö logo stays fixed on the left; only the right waveform animates.
Converted letters appear inline in cosmic orange. The result expands smoothly by only 22 points of width;
Ö and the waveform stay fixed, with matching result-body alignment. Idle animation stops; Low Power Mode and Reduce Motion
also pause animation. Input-triggered checks replace rapid polling.

Closing the main window keeps Sayqalchi in the menu bar. Click the ö menu to reopen,
pause, preview the floating bar, or quit.

The Playground works without Accessibility permission. Settings includes live
detection diagnostics, optional automatic full-text replacement after a pause,
and app exclusions. The suggestion always covers the entire focused draft,
even with a paragraph selected.
The entire field is supported up to 200,000 UTF-16 units. Longer fields are not
silently truncated: use the Playground for a smaller passage.

This preview is locally signed and is not Apple-notarized. A certificate-signed
build keeps its identity across updates. If you previously approved an ad-hoc
build, remove that old Yoz entry in Accessibility, then add this Sayqalchi app once.
Do not disable Gatekeeper. If macOS blocks it, use the normal Privacy & Security
Open Anyway flow for your own local build, or build from source on this Mac.

The formatting engine accepts Uzbek Latin and maps o' > ö, g' > ğ, sh > ş, ch > ç.
It preserves case and ng. Formatting does not translate languages or correct spelling. Use the new Translate tool for language and Cyrillic conversion. Other-language sh/ch words can also change; use suggestions
or exclude those apps. The alphabet comes from the PDF you supplied.

Cross-app support requires editable macOS Accessibility text fields with usable
text and selection APIs. Custom editors, remote desktops, and some browser
editors may not expose them. Such fields are skipped; use the Playground to copy
the transliterated result. Password fields and Terminal are skipped.

Formatting and document helpers run locally. While enabled, typing pauses automatically prepare translation and dictionary results online. Sayqalchi has no analytics, typed-text log, or clipboard monitoring. Web editors that ignore direct replacement use one
normal paste; Sayqalchi restores your previous clipboard unless you copied something
newer. Copy result in the Playground intentionally updates your clipboard.

Independent app inspired by Echo. Not affiliated with VoiceLab.

New in 0.5.0 preview:
Hover over the notch to open Format, Translate, Izohchi and Document tools.
The pencil opens manual input. Refresh captures the active editable draft again.
Translate supports Uzbek-English, Uzbek-Russian and Uzbek Latin-Cyrillic in both
 directions. New installs use MyMemory without a login, URL or key (5,000
characters/day, provider limits apply). MyMemory may retain submitted text.
Latin-Cyrillic conversion runs locally. In Settings > Translation service choose
Custom service to use your own URL/key; keys are saved in Keychain. Choose Settings > Default service. Only that tool runs after a pause; other tools
run when you open their tab. Format is the default and uses no network.
HTTP requires an explicit opt-in and exposes your key/text to the network.
Izohchi uses free public Izoh.uz entries. Select a word or enter a short phrase,
then pause and hover. The preview shows two meanings, one example each; More opens
all meanings in a larger notch. Savodxon is linked for manual browsing.
Document shows counts and read time, and previews spacing cleanup locally.
Copy is always explicit. Applying a result verifies the original full draft has
not changed; pasted manual text can be copied but cannot overwrite another app.
